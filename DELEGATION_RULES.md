## DECISION LOGIC

1. Check task keywords against triggers
2. If multiple matches, use this priority:
   - SURVIVAL (if security/threat related)
   - DATA (if research/analysis needed)
   - INNOVATION (if building something new)
   - LEVERAGE (if executing existing process)
   - HUSTLE (if business opportunity)
   - BRANDING (if communication/docs)
   - VISIBILITY (if marketing/SEO)
3. If unclear, Joe asks user for clarification
4. Complex tasks may require multiple departments (coordinate via sessions)

## ESCALATION

Escalate to Joe if:
