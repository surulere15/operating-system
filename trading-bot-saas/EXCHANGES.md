### **Step 1: Update Frontend Dropdown**
```tsx

<option value="new_exchange">New Exchange</option>
```

### **Step 2: Add Instructions**
```tsx
{formData.exchange === 'new_exchange' && (
  <ExchangeInstructions
    exchange="New Exchange"
    url="https://newexchange.com/api"
    steps={[
      'Go to API Management',
      'Create API Key',
      'Enable: Trade, Read',
      'DO NOT enable: Withdraw',
      'Save credentials'
    ]}
  />
)}
```

### **Step 3: Backend Auto-Supports It**
```python

exchange = getattr(ccxt, exchange_name)({
    'apiKey': api_key,
    'secret': api_secret,
    'enableRateLimit': True
})
```
