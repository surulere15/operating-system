## 📦 INSTALLATION & SETUP

### **1. Clone Repository**
```bash
git clone <repository-url>
cd trading-bot-saas
```

### **2. Backend Setup**
```bash
cd backend

# Install core dependencies
pip install -r requirements.txt

# Install ML dependencies (Phase 5)
pip install -r requirements-ml.txt
pip install -r requirements-sentiment.txt
pip install -r requirements-onchain.txt

# Setup environment variables
cp .env.example .env
# Edit .env with your API keys

# Initialize database
python -c "from database import init_db; init_db()"

# Run server
uvicorn main:app --reload
```

### **3. Frontend Setup**
```bash
cd frontend

# Install dependencies
npm install

# Run development server
npm run dev
```

### **4. Configure API Keys**

Create `.env` file in backend:
```bash
# Database
DATABASE_URL=postgresql://user:password@localhost/tradingbot

# JWT
JWT_SECRET=your-secret-key

# Stripe
STRIPE_SECRET_KEY=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...

# Twitter (for sentiment analysis)
TWITTER_BEARER_TOKEN=your_twitter_token

# NewsAPI (for sentiment analysis)
NEWS_API_KEY=your_newsapi_key

# Blockchain Explorers (for whale tracking)
ETHERSCAN_API_KEY=your_etherscan_key
BSCSCAN_API_KEY=your_bscscan_key
POLYGONSCAN_API_KEY=your_polygonscan_key

# Exchange APIs
BINANCE_API_KEY=your_binance_key
BINANCE_SECRET=your_binance_secret
```

### **5. Train ML Models (Optional)**
```bash
# Train deep learning models on historical data
curl -X POST http://localhost:8000/api/ml/train/BTC-USDT?days=365 \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```
