# Outreach Scripts — SKU05 Contract Renewal Trap Detector

## 1) Cold DM (LinkedIn) — ultra short
Subject: quick renewal risk check

Hey {Name} — we run a 24h “renewal trap” scan.
You upload 5 vendor contracts → we return a renewal calendar + auto-renew notice deadlines + renegotiation targets.

If we find zero actionable risks, full refund.
Want me to send the intake link?

## 2) Cold email — 90 seconds
Subject: avoid accidental renewals (24h scan)

Hi {Name},

Most teams lose money on renewals because cancellation windows + auto-renew clauses are buried in PDFs.

We offer a 24-hour Contract Renewal Trap Detector:
- renewal calendar (CSV + calendar import)
- auto-renew risks ranked by “must act by” date
- renegotiation/cancel targets

Starter: $499 for 5 contracts, delivered in 24h.

If useful, reply “scan” and I’ll send the upload + payment link.

— Sam

## 3) Follow-up 1 (48h)
Subject: should I close the loop?

{FirstName} — quick bump.
Do you want the 24h renewal scan, or should I close this out?

## 4) Follow-up 2 (7 days)
Subject: last note — renewal calendar in 24h

If you’ve got vendor PDFs in Drive, we can turn them into a renewal calendar + notice deadlines within 24h.
Worth it this month?

## 5) Close call (5 minutes)
Agenda:
1) How many vendor contracts do you have?
2) Any renewals in next 90 days?
3) Where are docs stored (Drive/email/Dropbox)?
4) Confirm package + deliverable time.
5) Collect payment + intake.

Objection killers:
- “We already track renewals” → “Cool—send 5 PDFs. We’ll identify auto-renew / escalators / notice windows you might be missing and return a clean calendar + evidence.”
- “Too busy” → “No meeting needed. Upload folder, we deliver tomorrow.”
- “Price” → “One missed notice window typically costs more than $499.”
