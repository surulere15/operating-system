# Execution Checklist — 7 Days to First Paying Customers (SKU05)

## Day 0 (Today)
- [ ] Create Stripe payment links: $499 / $1,500 / $3,000 setup
- [ ] Create intake form (Typeform/Tally/Google Form): name, company, role, email, #contracts, renewal urgency
- [ ] Create upload channel: Drive folder request or simple upload portal
- [ ] Prepare 1-page landing (Carrd/Framer/Notion): offer + guarantee + samples
- [ ] Record 2–3 min Loom showing sample report

## Day 1
- [ ] Build lead list (100–200): titles (Finance Ops, Procurement, COO, Ops Mgr, RevOps)
- [ ] Send 50 DMs + 50 emails
- [ ] Post 1 LinkedIn post: “auto-renew traps cost real money; 24h scan”

## Day 2
- [ ] Send 200 more outreaches (split across channels)
- [ ] Close 1–3 calls (5 minutes each)
- [ ] Deliver first paid report (even if concierge/manual)

## Day 3
- [ ] Turn first delivery into testimonial (quote + screenshot)
- [ ] Add testimonial to landing
- [ ] Run second batch outreach (200)

## Day 4
- [ ] Add “Calendar import” feature + reminder emails (simple)
- [ ] Upsell ongoing tracking ($299/mo)

## Day 5
- [ ] Partner outreach: fractional CFOs, procurement consultants, MSPs
- [ ] Offer 20% affiliate rev share for referrals

## Day 6
- [ ] Publish 3 case snippets (anonymized): savings prevented, deadlines found
- [ ] Retarget warm leads

## Day 7
- [ ] Review pipeline: conversion rate, objections
- [ ] Decide: double-down on SKU05 or pivot wedge to SKU06/SKU07

## Metrics to track daily
- # outreaches sent
- reply rate
- booked calls
- paid conversions
- avg delivery time
- # actionable traps found per client
