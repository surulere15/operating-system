# Growth Flywheel (v0)

## Flywheel Path (current product)
1) **Open / Return** → user sees **one obvious next action** (Quick Resume)
2) **Complete a step** → immediate feedback + **open loop** (“Step X is ready”)
3) **Progress visibility** → “Since last time” delta + Memory Shelf moments
4) **Prepared next step** → resume effort stays low (<5s target)
5) **Repeat** → sessions tighten and confidence rises

## Where growth can attach (later)
- After a strong outcome moment (step completion + delta), show a **soft invite** (no referral system):
  - “If someone you care about would benefit, invite them.”

## Guardrails
- First success < 60s
- Resume < 5s
- No dead ends; one next action per screen
- Small refinements only; avoid redesign
